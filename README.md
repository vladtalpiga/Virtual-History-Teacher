# Virtual History Teacher: Pedagogical Chatbot and Automatic Detection of Contradictions Between Historical Sources:

The "Virtual History Teacher" application is an educational project that aims to give 7th-grade students easy access to information about history lessons. Through this application, students can ask questions about the subject and receive answers tailored to their level of understanding.

The project also explores a scientifically relevant issue: the extent to which historical sources contradict one another. Starting from a user's question, the system analyzes multiple sources and automatically identifies any potential contradictions or discrepancies between them.
